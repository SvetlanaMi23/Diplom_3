# Diplom_3

Дипломный проект Автотесты Stellar Burgers. в Yandex и Chrome для Sprint4

## Совместимость

Java 11. Maven 3+

## Быстрый запуск

`$ mvn test`

## Настройка

В файле `config.json` в поле `browser` настраивается браузер, в котором будут проходить тесты.  
`browser` принимает значения: `сhrome` для  Google Chrome и `yandex` для Яндекс Браузере.  
Для запуска в Яндекс Браузере необходимо, чтобы он был установлен на компьютере.  
Вэб драйвер версии `25.6.0-stable` `yandexdriver.exe` для запуска в Яндекс Браузере лежит в проекте.
